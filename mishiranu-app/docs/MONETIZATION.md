## 全国ストック方針（2026-11-14 確定）

一気の全国 API 埋めはしない。

**優先（2026-11-14）:** 散歩アプリの核は土地の文章。触る線の土地文を厚くしてから、地図・全国ペースを伸ばす。

**正本の順位（2026-11-14・淡島様）:**  
1. **土地の「歩き方」（walkGuide）** … いちばん大事。ここに出た場所・順が「歩く」の骨  
2. 土地のほかの文（この駅・歴史・寄るところ）  
3. 地図・spots・Search … 歩き方を支える。文に無い名所で歩き方を上書きしない  

1. **土地文** … Gemini Pro（月額）で線ごと → `docs/land-stock/` → AREA_DEPTH  
2. **散歩地図** … 収録土地がある駅は spots 寄り Search。無い駅は通常生成  
3. **ペース** … Search 無料枠（月5,000回）内で月次。目安 **9〜18か月** で約9,000駅相当  
4. **共有** … できた駅はさくらキャッシュへ（2人目以降ほぼ¥0）  
5. **アプリ容量** … 全国全文は焼かない。好きな線だけ AREA_DEPTH、残りはキャッシュ／生成  

### Search枠の使い方（分散バッチ）

- 月 **5,000** 回無料＋目安 **日1,500** 上限 → 月末一括だと枠を余らせやすい  
- 月5,000を使い切るには **最低4日** に分ける（1500×4＝6000＞5000）  
- おすすめ: **週1〜2回 × 約800〜1,200検索分**（駅数にすると spots寄りでおおよそ **100〜200駅／回**）  
- 例カレンダー: 第1・第2・第3・第4週に1バッチずつ（合計で月枠付近）  
- 土地文（Pro）は Search を食わないので、バッチ前の週に線ごと書いておく  
- 実行: `npm run batch:land-spots`（dry は `:dry`）。収録土地駅のみ。詳細は `docs/land-stock/README.md`
