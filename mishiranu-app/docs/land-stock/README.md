# 土地文ストック

Gemini Pro（チャット月額）で先に貯めた **駅の土地の文章だけ**。
店リスト・座標・営業は含めない。アプリ本番の `AREA_DEPTH` / 生成 API とは別層。

## 方針

- 量産の第一稿。正本（出町柳・二ノ瀬・中書島など）は通常上書きしない
- **例外（2026-11-16）:** 第一稿〜50駅（出町柳含む · 叡電・京阪・烏丸洛内・嵯峨野）を Argon 高で再生成。索引 `PROMPT-first50-argon.md`。正本も上書き可。**手動貼付のみ**（自動送信しない）
- 取り込み前に徒歩分・出口・固有名を通す
- 店の固有名は書かない（書いたら削る）
- **storyNotes（本・映画）はここでは作らない**（アプリの物語経路）
- **walkGuide（歩き方）がいちばん大事**（2026-11-14）。ここが「歩く」コースの正本。spots は文章に書いた場所を地図で支える側

### 運用 B · 土地文先行（2026-11-15 確定）

**どんどん土地文を集める。spots（Search）は取込のたびに走らない。**

| いつ | 何をする |
|------|----------|
| Gemini チャット貼付のたび | md + `*-land-depth.ts` + AREA_DEPTH 配線のみ |
| ユーザーが駅を開いたとき | 土地文は正本。spots が無ければそのとき（または週バッチ） |
| 週1〜2回だけ | `batch-land-spots`（無料 Search 枠内 · 触った線優先） |

禁止: 土地文取込の直後に毎回全駅 spots を回す（Search を食い潰す）。

### いまメモ（日付つきパッチ · 2026-11-15）

土地文の正本（`*-land-depth.ts`）は書き換えない。高架化・改称・出口・工事など **駅のいま**だけを重ねる。

- 正本: `lib/mishiranu-land-now-notes.ts`（駅 id → `{ date, body }`）
- 表示: `withAreaDepth` が intro 末尾に `いま · YYYY-MM-DD — …` を付ける
- 書かない: 店の開閉・営業・座標
- 例: 淡路（`awaji-hankyu`）の高架工事メモ

## 生成の節約（2026-11-14）

収録土地文がある駅は API 生成時:

1. 土地文は正本のまま（Flash-Lite に書き直させない）
2. Search は spots・路線・座標など地図用だけ
3. 穴埋め Search は sight spots 不足のときだけ（土地の薄さでは打たない）
