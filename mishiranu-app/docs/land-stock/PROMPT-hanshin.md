## このまま Gemini に貼る（共通＋L）

```
見知らぬ駅アプリ用の「土地文」だけを書いてください。最高精度で。

【書く】
stationIntro（3〜5文）
walkGuide（一周できる歩き。橋・坂・川・旧道・大通り・改札・出口など固有名を入れる）
historyNotes（見出し＋本文を必ず3件。地形・街区・由来といまの見え方）
sightseeingNotes（必ず1〜3件。空にしない。正式名＋駅からの徒歩分＋着いたら何が見えるか）

【書かない】
- 店リスト・営業・座標
- storyNotes（本・映画・ドラマ）
- 隣の駅の名所の寄せ合い
- 観光パンフ口調・抽象語だけの紹介
- 店の固有名（チェーン含む。博物館など施設の正式名は sightseeing として可）

【必ず守る】
1. 開業年・駅名・路線名は正確に（路線名は「阪神本線」）
2. 同名・乗換駅の他社文をコピーしない（キー注意を守る）
3. sightseeing を空にしない
4. walkGuide は実際に歩ける一周。行きっぱなし禁止
5. この駅固有の地形・鉄道構造・街区を優先
6. 神社・寺・橋・陵の正式名を揺らさない

【出力形式】
駅名
stationIntro
（本文）
walkGuide
（本文）
historyNotes
見出し
本文
（×3）
sightseeingNotes
⚬ 名称: 名称です。改札から○へ徒歩約○分。着いたら見えること。

- 「今津」は阪急今津線と乗換可だが、阪急側の文をコピーしない。阪神改札から歩ける範囲
- 「西宮」≠ 阪急西宮北口・≠ JR西宮。阪神西宮駅の街区だけ

- 「鳴尾・武庫川女子大前」は正式駅名を崩さない
- 「芦屋」は市域全体の百科にせず、駅徒歩圏の地形・川・街区だけ
```
