## コアバリュー

地図アプリではなく、「思いがけない寄り道」の演出装置。

- 検索疲れを終わらせる（時間と半径で切る）
- 有名スポット偏重を避ける（徒歩圏のローカル）
- 「何もない駅」を失敗ではなく体験にする

## MVP（いまのスコープ）

1. **降り立つ** — 編集駅リスト + 滞在時間（1h / 3h / 半日）
2. **物語** — 編集コピー、または `GEMINI_API_KEY` があるとき AI 生成
3. **地図** — 徒歩圏の抽象マップ + ジャンル別ピン
4. **シークレット** — 「とりあえずここに行け」
5. **空白肯定** — 美瑛・姨捨・根府川・月崎など

## 非目標（当面）

- Places 自動取得の全国展開
- Mapbox / Google 実地図
- 乗り換え・時刻表・口コミ・予約
- 最適ルートナビ
- iOS 出荷（Web の感触が固まってから）

## 技術メモ

- 駅データ: `data/mishiranu-stations.ts`
- コピー API: `POST /api/mishiranu/copy`（キーなしは編集文にフォールバック）
- 秘密情報: `GEMINI_API_KEY`（未設定でもプロトは動く）

## 次の作業候補

1. 抽象マップの空気感をさらに磨く（モーション・余白・共有カード）
2. `GEMINI_API_KEY` を入れて AI コピーの温度を見る
3. 編集20駅の文面を実地・写真メモで更新
4. 感触が固まったら Mapbox / Google 実地図へ差し替え設計
5. Web が安定したら iOS
