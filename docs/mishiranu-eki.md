# 見知らぬ駅 — プロダクトブリーフ

> 降りた駅の、徒歩圏だけを、物語にする。

Lagado Lab の企画メモ。触れるプロトタイプは `/lab/mishiranu-eki`。

## コアバリュー

地図アプリではなく、「思いがけない寄り道」の演出装置。

- 検索疲れを終わらせる（時間と半径で切る）
- 有名スポット偏重を避ける（徒歩圏のローカル）
- 「何もない駅」を失敗ではなく体験にする

## ターゲット

| 対象 | 状況 | 届ける感覚 |
| --- | --- | --- |
| 青春18系ののんびり旅人 | 知らない駅に降りた直後 | 「ここに用があった」と思える偶然 |
| 出張のすきま時間 | 1〜2時間余った | 遠出なしの味わいある寄り道 |
| 行き先未定の休日 | 家を出たが決めきれない | 選ばなくていい、ひとつ提示 |

## MVP（必要最小）

1. **降り立つ** — 駅名 or 現在地 + 滞在時間（1h / 3h / 半日）
2. **物語** — ツアータイトルとキャッチ（AI or 編集テンプレ）
3. **地図** — 徒歩圏のジャンル別ピンのみ
4. **シークレット** — 「とりあえずここに行け」ガチャ
5. **空白肯定** — 観光地ゼロ駅のポジティブ表現

## 非目標

- 全国網羅ガイド
- 乗り換え・時刻表
- 口コミ SNS
- 予約・決済
- 厳密な最適ルートナビ

## 開発段階

| Phase | 内容 |
| --- | --- |
| 0 | モック駅 + 抽象マップ + 定型コピー（本リポジトリのプロト） |
| 1 | 駅ジオコーディング / Places / コピー生成 / PWA |
| 2 | 何もない駅モード強化、共有カード |
| 3 | iOS 出荷、Lagado カタログ掲載 |

## いま決めること

1. 最初の出荷: Web プロト → iOS か、最初から iOS か
2. データ: 編集キュレーション優先か、Places 自動か
3. 地図: 抽象 → Mapbox か、最初から Google/Mapbox か
4. AI: 命名・総評のみか、ルート提案までか

推奨（Lagado らしさ優先）: **編集20駅 → 抽象マップで感触固め → コピーに AI → 後から実地図と iOS**。
